# Finanças Descomplicadas

Create the complete visual foundation of a premium personal finance web application for students.

IMPORTANT:

This phase is ONLY about visual design, layout, navigation structure, responsive behavior and UI components.

DO NOT implement backend functionality yet.

DO NOT create database logic.

DO NOT create authentication.

DO NOT create Supabase tables.

DO NOT implement financial calculations.

DO NOT connect APIs.

DO NOT implement Google Sheets.

DO NOT implement real data persistence.

DO NOT implement real forms or financial transactions.

Everything should use realistic mock data for visual presentation only.

The application will later become a complete online financial management platform where each student will have their own account, their own financial data and their own saved information. Therefore, build the visual architecture in a way that is ready to receive these functionalities later, but DO NOT implement them now.

The application language must be Brazilian Portuguese (pt-BR).

The visual identity must NOT look like Lovable.

It must NOT look like an AI-generated dashboard.

It must NOT look like a SaaS template.

It must NOT look like an administrative system.

The final result should feel like a professionally designed financial technology product created by a high-end product design studio.

==================================================

CORE DESIGN DIRECTION

==================================================

Use the provided visual references as inspiration, especially the dark premium financial dashboard aesthetic.

Primary visual colors:

#0F0F0F — primary background

#202020 — cards and elevated surfaces

#5DD62C — primary accent / action color

#337418 — deep green

#F8F8F8 — primary light text and surfaces

You may introduce very subtle neutral shades derived from this palette when necessary for hierarchy, borders and secondary text.

The interface should feel:

- Premium

- Modern

- Minimal

- Sophisticated

- Intuitive

- Financial

- Confident

- Clean

- Fast

- Professional

- Visually memorable

Avoid excessive gradients.

Avoid glassmorphism.

Avoid excessive shadows.

Avoid excessive borders.

Avoid excessive icons.

Avoid visual clutter.

Use depth through spacing, contrast, typography and subtle elevation rather than decorative effects.

==================================================

DESIGN PHILOSOPHY

==================================================

The most important principle is:

"Complex financial information should feel simple."

The student should immediately understand:

1. Where they are

2. What their financial situation looks like

3. What requires attention

4. What they can access next

The application should feel extremely intuitive even for someone who is not good with finances.

Do not overload the screen with information.

Use progressive disclosure:

show the most important information first and allow deeper information to appear inside dedicated sections.
